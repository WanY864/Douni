# Unity 设置

1. Unity Hub 安装 Unity 6，创建 2D Core 项目。
2. 将仓库内 `UnityProject/Assets` 复制到项目目录。
3. 在场景中创建空 GameObject，命名 DouniApp，挂载 DouniDemo。
4. 确认场景有 EventSystem（没有则 GameObject > UI > Event System）。
5. 启动本地代理，再运行 Unity 场景。
6. 在 Inspector 可设置 Streaming、Typing Indicator 和代理地址。
