# 设置、记忆与排错

1. Unity Hub 安装 Unity 6，打开仓库中的 `UnityProject/`。
2. 场景中新建空 GameObject，挂载 `DouniDemo.cs`；确保有 EventSystem。
3. 终端进入仓库 `proxy/`，运行 `npm install` 和 `npm start`。
4. 运行 Unity，在密码框输入 DeepSeek API Key。

## 用户记忆
本地记忆默认开启，红、蓝 NPC 分别保留最近最多 80 条聊天消息，存放在 Unity 的 persistentDataPath。每次 API 请求只发送对应 NPC 人设和最近最多 20 条对话，不使用供应商端记忆服务。游戏内“本地记忆”开关关闭时会删除本地记忆文件；“清空本轮”清除当前角色历史。

API Key 仅在运行时内存中短暂使用，不进入本地记忆文件、PlayerPrefs、日志或 Git，退出时清空。注意本地记忆是普通本机文件，不是加密保险库；多人共用电脑时请关闭记忆或清除历史。

## 排错
- **Key 错误/无权限**：确认 DeepSeek API Key 有效且可调用所选模型。
- **余额或额度不足**：检查 DeepSeek 账户余额和调用额度。
- **429**：降低请求频率后重试。
- **代理连接失败**：确认 `npm start` 正在运行，地址为 `127.0.0.1:3000`。
- **请求超时**：检查网络后重试；代理和 Unity 请求超时均为 90 秒。
- **中文显示异常**：导入支持简体中文的字体并替换 UI 字体。
