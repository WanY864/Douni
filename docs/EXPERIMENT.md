# HCI 实验方案

## 研究问题
1. Streaming 是否让用户更早感知到系统正在响应，并改善等待体验？
2. Typing Indicator 是否能降低用户对系统状态的不确定感？

## 实验设计
采用 2×2 条件组合：Streaming（开/关）× Typing Indicator（开/关）。如课程要求只选两个方向，报告中分别讨论两个主效应。每位参与者完成相同的 4 个简短问题，条件顺序随机或轮换，避免顺序效应。

## 测量
- 首 token 延迟：发送至首个回复字符的毫秒数
- 总响应时间：发送至完整回复结束的毫秒数
- 主观等待感：1（很短）—7（很长）
- 状态清晰度：1（完全不清楚）—7（非常清楚）
- 总体满意度：1—7

## 流程
1. 说明任务并取得同意，不收集姓名等身份信息。
2. 参与者分别与红、蓝 NPC 完成指定问题。
3. 每个条件后填写 3 个 1—7 分题项。
4. 结束后询问偏好及原因。
5. 汇总均值、中位数和条件差异；样本较小时以描述性统计为主。

## 问卷题项（1—7 分）
- 我能判断 AI 是否正在处理我的问题。
- 等待回复的过程让我感到可以接受。
- 回复呈现方式让我更愿意继续对话。
- 我对这次交互总体满意。

## 数据伦理
只记录随机参与者编号、实验条件和交互时间；避免记录个人敏感信息。真实实验完成后再填写结果，禁止编造参与者数据。云端模型和网络波动是实验限制，应记录实验日期、模型名称和网络环境。
